# MEME CASE — апгрейдер мем-скинов

Flask-приложение: регистрация и вход, кейсы, круговой апгрейдер с выбором
цели, витрина персонажей, инвентарь с продажей, публичные профили и загрузка
собственного аватара.
В каталоге 54 персонажа на основе переданных фотографий.
Игровая логика (баланс, RNG выпадения, шанс апгрейда и продажа) считается
на сервере (`app.py`), фронтенд —
`templates/index.html`.

## Структура

```
meme_case/
├── app.py                # сервер + игровая логика (Flask, Python)
├── templates/
│   └── index.html        # HTML/CSS/JS страницы
├── requirements.txt
└── README.md
```

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Открой в браузере: http://127.0.0.1:5000

## Проверки

```bash
python -m unittest discover -s tests -v
```

Тесты используют временную копию приложения с отдельной базой данных.

## Важно

- Автоматическая покупка и демо-начисление отключены. Для покупки монет
  интерфейс направляет пользователя в Telegram: [@wefrqq](https://t.me/wefrqq).
- Учётные записи и аватары сохраняются локально в SQLite и `static/uploads`.
  Игровой баланс и инвентарь хранятся в памяти процесса (`GAME_DB`), поэтому
  при перезапуске сервера игровой прогресс сбрасывается.
- Настройка «Телефон / ПК» в разделе ⚙️ Настройки переключает
  раскладку интерфейса.
- В «Инвентаре» предметы продаются за 70% стоимости. При прокрутке закреплена
  шапка с названием, видом и ценой; эти же данные отображаются на рулетке кейса.
- Кейсы и витрина отсортированы от дешёвых к дорогим. Каждый кейс имеет
  серверный диапазон выпадающих цен: дешёвые кейсы не выдают самый дорогой лут.
- «БЕСПЛАТНЫЙ» открывается за 0 M без ограничений после входа в аккаунт,
  включая нулевой баланс. Из него выпадают только 11 новых персонажей за
  1–9 M: они дешевле всех прежних персонажей (прежний минимум — 10 M).
- Кейсы, от самого дешёвого до самого дорогого: «БЕСПЛАТНЫЙ», «БОМЖ», «ШКОЛЬНЫЙ ОБЕД»,
  «РОВНЫЙ ВАСЬ», «КРУТОЙ SLAYER», «TRUE AM AM», «MELLSTROY», «ВОРКЕР»,
  «MEME CASE».
- Персонажей 54: 43 прежних + 11 новых в тире «Хлам» за 1–9 M.
- Все 9 кейсов используют PNG-рендеры с прозрачным фоном из `static/cases`.
  Картинки отображаются в каталоге и в окне подтверждения открытия.
- У апгрейда выбирается конкретный персонаж-цель; шанс рассчитывается на
  сервере из соотношения стоимости исходного предмета и цели и всегда
  находится в диапазоне 75–95%.
- Перед открытием кейса на фронтенде показывается модальное окно
  подтверждения покупки с ценой и диапазоном дропа.
- В админ-панели у администратора есть отдельная кнопка «Начислить себе»,
  которая начисляет монеты только на его собственный аккаунт; все остальные
  действия (списание, выдача предметов, бан) по-прежнему нельзя применить
  к самому себе.
